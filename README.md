# Семейный бюджет

Админка для учёта расходов и накоплений. Публикуется на GitHub Pages.

## Как устроена защита

GitHub Pages отдаёт только статические файлы, поэтому настоящей серверной авторизации здесь нет,
а весь код в репозитории публичный. Чтобы при этом посторонние не видели админку, её содержимое
(`src/admin.html`) зашифровано AES-256-GCM, и в опубликованный `index.html` попадает только шифротекст.
Ключ выводится из логина и пароля (PBKDF2-SHA256, 600 000 итераций). Без пароля страницу не открыть,
даже прочитав код. Пароли в репозиторий не попадают.

Ограничения: подбирать пароль можно офлайн, поэтому он должен быть длинным и случайным.
Исходник `src/admin.html` публичный (это только интерфейс без данных). Если интерфейс тоже нужно
скрыть, репозиторий можно сделать приватным (Pages из приватного репо требует платный план GitHub).

## Где хранятся данные

Записи хранятся только в браузере (localStorage) на конкретном устройстве и никуда не отправляются.
Между устройствами их можно переносить через «Экспорт / Импорт». Реальные финансовые данные
в репозиторий не коммитятся.

## Сменить пароли или добавить пользователя

Нужен Node.js 18+.

```sh
node tools/build.mjs        # спросит логины и пароли
git add index.html && git commit -m "Обновить пароли" && git push
```

После смены паролей старые перестают работать.
Если меняли `src/admin.html`, тоже пересоберите `index.html` этой командой.
